## 2. 本次学到的知识

- 持久配置与运行状态分别检查 → 配置文件中存在实验室网络，但运行列表标记为 `DISABLED` → 检查备用网络时同时核对文件、运行优先级及启用状态。
- 数值越大越优先 → 热点设为 20，实验室设为 10 → 两网络可用时为 supplicant 的网络选择提供优先顺序。
- 只修改必要字段 → 替换 priority 后去除数值差异进行全文比较 → 可以确认 SSID、凭据及其他配置保持一致。
- 不同验证证明不同事实 → 配置读回证明已保存，实际解码证明本次仍可取流 → 配置完成不能代替重新上电和断网切换验收。
