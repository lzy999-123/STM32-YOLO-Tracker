## 写作与查阅

- 新报告采用 [学习报告模板](TEMPLATE.md)，同日多次提交递增文件名序号。
- 记录失败和修正，保留“为什么这样做”的依据，不只罗列功能。
- 当前提交通过报告文件的Git历史关联；报告中可记录修改前基线SHA和本次提交主题。
- 项目完成后按 [项目总结提纲](PROJECT_SUMMARY.md) 汇总，当前提纲尚未填写为最终结论。
- 报告制度见仓库根目录 [AGENTS.md](../../AGENTS.md)。
