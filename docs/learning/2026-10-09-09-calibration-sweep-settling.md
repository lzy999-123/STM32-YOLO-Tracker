## 2. 本次学到的知识

- 读取时刻影响扫角判定 → 扫描结束时若转子仍跟随滞后，正反终点差可能偏小 → 在反馈达到稳定条件后采集端点，并设等待上限。
- 移植时序应与原厂逐项核对 → 原厂500步、移植版300步，步间隔同为2ms → 算法公式相同也要核对动态时序。
- 通过模拟只能验证候选机制 → 合成26ms滞后可造成旧代码拒绝、新代码通过 → 将模拟结果与实际电机读数分开，待实测确认。
- 新增等待必须继续处理停止 → 每次等待检查PC15和传感器，超时退出 → 有输出的等待不使用无限循环或忽略中止。
