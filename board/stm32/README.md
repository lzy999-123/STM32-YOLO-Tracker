# STM32 OLED Wi-Fi 页面与 PC13 按键

## 正式工程与更新内容

当前正式固件在 `D:/STM32CubeMx/hal_stm32/科教协同下位机-1`，Keil 目标为 `MDK-ARM/servo_duoji.uvprojx` 中的 `servo_duoji`，入口为 `Core/Src/main_gimbal.c`。

- PC13 短按：松开并消抖后切换云台状态页 / Wi-Fi 页，不改变控制模式或电机目标。
- PC13 长按：按住 1 秒切换自动 / 手动，仅触发一次；保留原模式切换的回中处理，松开不再切页。
- 上电时已按住 PC13：先松开再操作，避免启动期间的按住状态误触发。
- PC14 回中、PC15 急停 / 恢复及上电校准的原逻辑保留。故障、急停和校准页优先显示。
- Wi-Fi 页显示 Luckfox 当前已关联的网络名称；短名称静止，超过一行时先停留 1.5 秒，再每 0.5 秒向左移动一个字符，循环间留三格空白。
- Wi-Fi 页第三行保留当前自动 / 手动和控制通信状态。断网清掉旧名称；7 秒没有新报告显示“等待更新”。

显示使用现有精简字库；ASCII 与已收录汉字可正常显示，未收录的汉字或其他符号显示 `?`。滚动按字形边界移动，不拆开已支持的 UTF-8 汉字。

## 配套协议

| 方向 | TYPE | 内容 | 用途 |
| --- | --- | --- | --- |
| STM32 → Luckfox | `0x84` | 单字节 `0x01` | 声明支持新的 OLED Wi-Fi 元数据；跟随每秒校准报告发送 |
| Luckfox → STM32 | `0x05` | 状态 + 0～32 字节 SSID | `0`=未知，`1`=未连接，`2`=已连接；只有 `2` 携带非空名称 |

两端 UART LEN 上限由 32 改为 40，完整保留最多 32 字节的 SSID。原跟踪、命令、遥测和校准帧布局保持兼容。

Luckfox 通过 `wpa_cli -i wlan0 status` 获取实际关联状态，每 2 秒探测与上报。探测在后台线程执行，命令超时为 0.5 秒，UART 写入仍由原控制循环统一执行，无 Qt 会话也能上报。元数据不会更新 STM32 的控制心跳或使能电机。

新版桥接脚本只在收到新固件能力声明且遥测有效时发送 Wi-Fi 帧，避免旧固件把未知帧当成控制活动。需要同时使用新固件与新脚本，旧脚本无法提供名称。
